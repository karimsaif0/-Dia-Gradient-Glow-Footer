# Karim Saif Gradient

A production-ready Framer gradient glow component with curated presets, multiple visual styles, responsive SVG rendering, and optional reveal animation.

## Features

- 8 curated presets: Signature, Aurora, Sunset, Neon, Spectrum, Ember, Ocean, and Minimal
- Custom mode with detailed controls
- Gradient Bars, Layered Peak, and Color Dodge styles
- Adjustable bar count, overlap, peak height, edge height, pointiness, spread, blur, intensity, and opacity
- On-load and on-scroll reveal animation
- Smooth, Snappy, Gentle, and Linear easing options
- Reduced-motion support
- Static-renderer safe for Framer
- Accessible ARIA label control
- Unique SVG IDs for safe use of multiple instances on the same page
